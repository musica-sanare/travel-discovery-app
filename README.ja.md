# Travel Discovery

Travel Discovery は、都市・地域単位の海外の旅行先を推薦するレスポンシブな Web アプリだ。短く変化のあるクイズと、任意で入れる旅行の条件（日数、月、予算）から旅行先を選ぶ。診断は決定的で、AI なしで動く。任意の AI ノートは既定で OFF で、順位を変えることはない。結果には目安の費用の範囲を出典と日付つきで示し、リアルタイム価格は出さない。航空券とホテルの検索へのリンクもある。UI は日本語・英語・スペイン語・フランス語に対応し、既定は日本語。

## 状態

- Phase 0〜25 は完了してデプロイ済みで、本番には `content/initial-v12.json` をインポートしてある。
- 本番は https://travel-discovery.apps.musica-sanare.com で、AI を無効にして動いている（`workers.dev` の URL でも開ける）。`main` に push するたびに Cloudflare Workers Builds がデプロイする。35 か国・44 件の旅行先（13 の属性で採点）と、31 問のクイズの質問を提供している。
- Phase 14 で、AI の上限と提供状況を UI に表示し、利用者ごとの厳密な AI の回数制限を本番にデプロイした。
- Phase 15 で、有力な旅行先を見分けやすい質問をクイズが優先して出すようにした。
- Phase 16 で、出典つきの費用の目安を増やした。10 件の旅行先で `JPY`・`USD`・`EUR` の目安を出せる。
- Phase 17 で、UI と公開中のすべてのコンテンツにフランス語を加えた。
- Phase 19 で、結果ごとにほかの結果と比べて際立つ点を示し、ページの説明、リンクのプレビュー用のタグ、favicon を加えた。
- Phase 20 で、パブリックドメインの地図データからアプリ自身が描く結果の世界地図と、各結果から Google マップを開くリンクを加えた。
- Phase 21 で、英国、ポルトガル、北欧、中東、南アジア、アフリカなど 10 か国の行き先を 12 件加え、フィンランド・ラップランドに出典つきの費用の目安を加えた（費用のある旅行先は 11 件）。
- Phase 22 で、AI を有効にするかを決める前に、任意の AI ノートを固めた。ノートが旅行先自身の文章の数字を写せるようにし、1 件のノートの失敗でほかのノートを捨てないようにした。全利用者の合計で AI の呼び出しを UTC の 1 日 500 回までに抑え、各旅行先の適合度をモデルに見せないようにした。
- Phase 23 で、いちばん合う旅行先を最初に出したまま、残りの結果をほぼ同じくらい合う旅行先から選ぶようにした。結果はクイズごとに変わりうる。「ほかの候補を見る」で引き直せる。
- Phase 24 で、属性スコアを 12 か所直した。ケープタウンのように幅広く合う旅行先が出すぎるのを抑え、見つけにくかった旅行先のいくつかを見つけやすくした。ローマとマサイマラは少ないままで、新しい属性が要る。
- Phase 25 で、古代遺跡と野生動物という 2 つの属性とそれを使う質問、シェムリアップとガラパゴス諸島の 2 件の行き先を加えた。シミュレーションでは、ローマとマサイマラが見つかりやすくなった。リスボン、エディンバラ、コペンハーゲンは改善していない。
- 本番で AI を有効にする手順は用意してある。オーナーが承認するまで AI は無効のまま（[Implementation plan](docs/working/IMPLEMENTATION_PLAN.md)、英語のみ）。
- Phase 18 で、リポジトリを公開できる状態に整えた。履歴とシークレットのスキャン、MIT ライセンス、セキュリティポリシーを済ませた。オーナーが 2026-11-01 に公開した。公開した直後に入れる GitHub の設定は [Public release checklist](docs/working/PUBLIC_RELEASE.md)（英語のみ）にある。

## クイックスタート

必要なもの: Node.js `>=22.22.0`（`.nvmrc` では 24 に固定）と npm。Cloudflare のアカウント、ログイン、秘密情報はいらない。

```bash
npm ci
npm run db:reset:local
npm run dev
```

http://localhost:5173 を開く。

- `npm run db:reset:local` は既存のローカルの D1 データを消してから、マイグレーションを適用してシードデータを読み込む。
- `npm run check` で lint、型チェック、テスト、ビルドをまとめて実行する。
